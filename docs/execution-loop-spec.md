# 執行閉環實作規格（依《高效人生工作法圖解》）

> 來源：使用者與 Claude（claude.ai 桌面版）的討論，2026-11-22，經 Scout 收件匣交接。程式碼基準 v1.7.0（`9ef8efb`）。
> 檔案路徑與欄位名是建議，動手前先確認現況，有衝突以 repo 為準。

## 目標

書的閉環：第二大腦 → 選擇 → 行動與專案 → 時間管理 → 習慣 → 覆盤 → 人生計畫 → 回到第二大腦。
Scout 各環節大多已具備，缺的是環節之間的資料流：番茄鐘、任務、週回顧各自獨立。

## 優先順序

1. **番茄鐘綁任務**（最優先）— `PomodoroState.linkedTask`、`TodoItem.focusCount`；只有 focus 跑完才 +1；寫入經主視窗既有 handler（ADR 0009／0010）。驗收：跑完 +1、跳過不算、重開綁定仍在。
2. **週回顧自動帶入數據，下週目標一鍵轉任務** — `weeklyReviewUtils.computeRangeStats` 加本週完成待辦（`checkedAt`）、focusCount 合計、逾期數、收件匣剩餘；下週目標每行可轉待辦（到期日預設下週五）。空白週仍可一鍵結案。
3. **筆記裡的 `- [ ]` 自動成為任務** — 文字卡／Journal 的核取清單列進任務中心；可先唯讀，寫回第二步。
4. **卡片加時段** — `TodoItem.scheduledStart?／scheduledEnd?`；週檢視（`TimeGrid.tsx`）顯示並可從任務中心拖入。
5. **目標層級與習慣追蹤**（之後）— 目標卡或 goalId；習慣追蹤做成卡片類型或放 Journal。另：收件匣整理加「2 分鐘內做完」與「標為任務時設到期日」。

## 共通原則

- 不新增外部套件；純函式放 `utils/` 附測試；tsc、ESLint、Vitest 全綠。
- 不做團隊協作、發佈、Notion 式資料庫——Scout 定位是個人視覺工作台。
- 每項一個分支，完成後回報使用者，再決定是否合併、發版。
